Engraving Bible Uploader

YouTube  An internal upload tool for the YouTube channel 「성경을 새기다」 (@engravingbible).

The channel publishes a Korean Bible reading series — one chapter per video, the public-domain 1961 Korean Revised Version read word-for-word, with an original engraving-style illustration for each chapter and a short commentary.

What the tool does

  1. Our render pipeline produces an episode (video, thumbnail, captions, metadata).
  2. Automated checks review the metadata (title, description, source attribution, AI disclosure, chapters).
  3. The channel owner approves the upload and chooses its visibility in a web form.
  4. Only then the tool calls the YouTube Data API: videos.insert, thumbnails.set, playlistItems.insert, captions.insert.

The tool is used only by the channel owner, only for this one channel. It is not offered to other users.
