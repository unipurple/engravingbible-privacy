Privacy Policy — Engraving Bible Uploader

Last updated: 2026-10-17

Engraving Bible Uploader is an internal tool used only by the owner of the YouTube channel 「성경을 새기다」 (@engravingbible) to upload and manage videos on that channel. It is not offered to the public and has no other users.

What the tool accesses

Through the YouTube API Services, the tool uploads videos, sets thumbnails, adds videos to the channel's own playlists, and uploads captions — only for the channel owner's own channel, after the owner approves each upload.

What we collect and store

We do not collect, store, or share personal data of any other YouTube user. The only data kept is a local log of our own uploads (video ID, title, date). OAuth tokens are stored only on the owner's computer and are never shared.

Third parties

This tool uses YouTube API Services. By using it, the owner agrees to the YouTube Terms of Service, and data handled by Google is subject to the Google Privacy Policy. Access can be revoked at any time at Google security settings.

Data retention and deletion

OAuth tokens are kept only on the owner's computer and can be deleted at any time by removing the local token file or by revoking access at Google Account → Third-party access. Revoking access immediately stops the tool from using the YouTube API. Our local upload log contains only our own video IDs and titles; it is deleted on request or when the tool is retired. YouTube API data is not stored longer than needed (at most 30 days for any cached API data) and is never sold or shared.
